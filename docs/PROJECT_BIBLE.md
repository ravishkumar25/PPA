## Vision

Vexa is an AI-powered personal desktop assistant built under the Project Personal Assistant (PPA) initiative.

The goal is to build a Jarvis-like assistant that understands Hindi, Hinglish, and English, remembers the user, controls the computer, understands the screen, automates tasks, and communicates naturally.

---

## Long-Term Goal

Create the most advanced personal AI assistant possible using cloud AI, modern automation, and modular architecture.
